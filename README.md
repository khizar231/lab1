# CAI601400 — Artificial Intelligence Lab 1

## Contents
- `lab1_rules.py` — transparent scholarship rule engine and exactly four core tests.
- `lab1_compare.py` — reproducible comparison illustrating disagreement between explicit rules and an unsupported conversational claim.
- `Lab1_Report.docx` — report, timeline, test table, comparison, limitations, and reflection.
- `outputs.txt` — captured console output from both programs.

## Requirements
- Python 3.10 or newer (uses built-in `dataclasses` and type hints).
- `python-docx` is only needed if you want to regenerate the report; it is not needed to run the scripts.

## Run
From this folder:
```bash
python lab1_rules.py
python lab1_compare.py
```

## Assumptions and responsible use
All eligibility thresholds and conditions are synthetic teaching assumptions, not an official scholarship policy. Do not use this toy program to make real funding decisions. Use fictional applicant names only. Review policy, fairness, accessibility, privacy, and appeal procedures before any real deployment.
